# Cherry Seed

Landing page for Cherry Seed, the entrepreneurship program for Duvdevan alumni, an initiative of Friends of Duvdevan developed with the Adelson School of Entrepreneurship at Reichman University.

Static site: open `index.html` or serve the folder with any static host. No build step.

- `index.html` page markup and copy
- `styles.css` design system and layout
- `seed.js` the signature seed graphic (canvas)
- `main.js` hero refraction, header, journey stages, reveals
- `assets/` logos and toned photography (Geist loads from Google Fonts)

Applications go to the Airtable form linked from every Apply button.
